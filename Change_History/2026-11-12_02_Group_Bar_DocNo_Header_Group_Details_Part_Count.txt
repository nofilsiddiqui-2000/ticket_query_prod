WHY
- A query in a group only shows "Doc No. : <no>": users can't see it is part of a group
  until they click Edit Form.
- In edit mode the group banner is a pale yellow italic text with a run of spaces and a
  bright yellow underlined "Click Here" button placed over the gap. It looks unfinished
  and moves with screen size and zoom.
- Nowhere outside group edit tells the user how many parts the group has.
- Group details section (group edit only): table-like layout with navy lines; clicking
  its header text opens/closes section 1 (Parts Detail) instead of this section.

WHAT THE USER WILL SEE
- View mode, group query:  Doc No: CM-0012-00045 (Part of group CM-0012-00043, 4 parts)
- View mode, single query: Doc No: CM-0012-00045
- Edit mode, one part:     [i] Part of group CM-0012-00043 (4 parts). Field changes apply to
                           this iQuery only; files are shared with the group. [Edit whole group]
- Group edit:              [i] Group edit: your changes apply to all 4 parts in group CM-0012-00043.
- Group details section:   "Group size: 4 parts" + one card per query (Doc No on brown strip,
                           "P/N <part>" below), first query first.

IMPACT / RISK
- Look only + the group details section gets its own section number 9 (header text,
  arrow, height, Expand All). Today it shares 8 with the Misses Tracker, and its header
  text toggles section 1 (Parts Detail) by mistake.
- NOT changed: Button9.OnSelect (group edit + lock checks), the Visible of the bar, icon,
  button, PNQ_Header and Container30, saving, data, flows, other screens.
- Nothing outside these controls reads them (checked with grep): Label41, Icon12, Button9,
  PNQ_Header, Label45, Label45_3, Title7, Label46, Rectangle3 are read by no other control.
  Gallery8 is read only by Label45_1, Label45_2, Rectangle3_1 (hidden by CHANGE 14-16).
- Part count = CountRows(Filter(PNQ_Backlogs, BatchDocNo = <group no>)): the same formula
  Label45_3 already uses (App Checker: no delegation warning). It runs only for group
  queries (single queries: blank group no -> no data call), in view mode from PNQ_Header,
  in edit mode from Label41. One small data call when a group tab is shown.
- Old groups whose first query has a blank BatchDocNo (if any exist) count 1 too few. The
  current create code gives every part the BatchDocNo, so only old data could be affected;
  the existing group details count has the same limit.
- Group sort column "cr7ba_documentnumber" = DocNo in PNQ_Backlogs (References/DataSources.json).
- Section numbers: the Misses Tracker (Container_MissTracker) keeps 8. Both sections can show
  at the same time (Configuration Management user, group edit, department changed away from
  Configuration Management), so today the group details arrow also opens/closes the Misses
  Tracker. With 9 they open/close separately. Number 9 is used nowhere else. New tabs open
  with sections 1-6 (or 1) expanded, so the group details still start collapsed, as today.
  Collapse All clears every number (works for 9 too); Expand All gets 9 added (CHANGE 17).
- Doc No width 780 (view mode): the screen never gets narrower than 1366 px (app design
  width 1366, Scale to fit off, screen/form Width not overridden), so the box (293-1073)
  stays clear of the Days Aging timer (ends at 260) and Edit Form (starts at 1240). At
  125% browser zoom the page scrolls sideways instead of getting narrower.
- Defaults: where a BEFORE says "not set in the zip", the property is at Studio's default.
  The default shown is the expected value; check what Studio shows before you paste and
  note it here if it differs (needed for undo).

---------------------------- BEFORE - CHANGE 1 - Label41.Text --------------

    LookUp(colOpenTabs, TabID = varActiveTabID).isBatchEditing,
    "You are editing multiple iQueries together",
    "This query belongs to a group of queries.                               to update details of all the queries of this group together."

---------------------------- AFTER - CHANGE 1 - Label41.Text ---------------
With(
    {_tab: LookUp(colOpenTabs, TabID = varActiveTabID)},
    If(
        IsBlank(_tab.batchDocNo) || !_tab.isEditing,
        "",
        With(
            {
                _parts: CountRows(
                    Filter(
                        PNQ_Backlogs,
                        BatchDocNo = LookUp(colOpenTabs, TabID = varActiveTabID).batchDocNo
                    )
                )
            },
            If(
                _tab.isBatchEditing,
                "Group edit: your changes apply to all " & _parts & " parts in group " &
                    _tab.batchDocNo & ".",
                "Part of group " & _tab.batchDocNo & " (" & _parts & " parts)" &
                    ". Field changes apply to this iQuery only; files are shared with the group."
            )
        )
    )
)
---------------------------- END OF AFTER ----------------------------------
