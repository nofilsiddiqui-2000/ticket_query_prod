WHY
------------------------------------------------------------------------------
Allowed in a part number: letters, numbers, hyphen (-), slash (/), period (.).
Not allowed: cage codes (':' - and in the parts list also ',' or a space inside one
part number), other special characters, and the same part number twice in one
request (exact match, upper/lower case ignored; 'ABC' vs 'ABC-1' is NOT a duplicate).

Cause: the New Request box allows '/', but the Manage parts list popup checked
IsMatch(PartNumber, "[ ,/:]", Contains) and called a '/' a cage code. 'Create New
Request' -> Button7 builds the list without that check, so the error only showed
once the user typed a description, and then Save was blocked
('One or more Part Details contain errors'). Nothing checked for duplicates, and
Save creates one iQuery per row.

IMPACT / RISK
------------------------------------------------------------------------------
Changed: 7 properties on PartsQuerySystem (no new controls/variables, no renames).
Changes 6 and 7 are display text only.
Not changed: save logic (btnSaveClose / Form1 / HiddenSaveButton), colCreateQueue,
App.OnStart, data sources, flows, existing-query editing (the parts list popup is
only shown for new requests). Everything that reacts to a part error (yellow
border, red message, popup Save button, main Save check, warning icon) already
reads the 'error' field, so it works unchanged.
Behaviour differences: a tab or line break inside one part number in the popup is
now flagged; a part not in the master list shows '❗ Part Description cannot be
blank' instead of '⚠️ Please enter Part Description' after 'Add to list'.

THE CHANGE
------------------------------------------------------------------------------
Note: the parts list popup is hidden while editing in Studio. Clicking its controls
in the Tree view still opens their formulas.

        Blank()

---------------------------- AFTER - CHANGE 1 -----------------------------
With(
    {
        _parts: ForAll(
            Filter(
                Split(
                    Substitute(
                        Substitute(PartNumberTextInput.Text, Char(13), " "),
                        Char(10),
                        " "
                    ),
                    " "
                ),
                !IsBlank(Trim(Value))
            ),
            {Value: Trim(Value)}
        )
    },
    With(
        {
            _duplicate: First(
                Filter(
                    _parts As p,
                    CountRows(Filter(_parts, Lower(Value) = Lower(p.Value))) > 1
                )
            ).Value
        },
        If(
            CountRows(Filter(_parts, ":" in Value)) > 0,
            "⚠️ Part number must not contain cage code",
            !IsBlank(PartNumberTextInput.Text) && !IsMatch(
                PartNumberTextInput.Text,
                "^[A-Za-z0-9\-\/\.\r\n\s]*$"
            ),
            "⚠️ Part number can contain only alphanumeric characters, hyphen(-), forward-slash(/), or period(.)",
            !IsBlank(_duplicate),
            "⚠️ Duplicate part number: " & _duplicate & ". Please enter each part number only once.",
            Blank()
        )
    )
)
